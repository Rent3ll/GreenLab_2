## 4. Дефекты
### BUG-01
Требование: R05
Заголовок: Нарушение гистерезиса насоса на нижней границе (humidity=35).
Начальное состояние и шаги: S02 (humidity=35, состояние до: OFF).
Ожидание с обоснованием: насос должен сохранить OFF (R05). Факт: насос=ВКЛ.
Серьёзность: Средняя. Дребезг реле насоса при влажности около 35%.
Причина в candidate.js: Неверное условие `humidity <= 35` в `pumpStart` вместо строгого `< 35`.
Исправление: `pumpStart: humidity => humidity < 35`.
Регрессия: S01 (PASS), S02 (стал PASS), S03 (PASS).

### BUG-02
Требование: R09
Заголовок: Нарушение приоритета вентиляции при распределении бюджета (budget=3).
Начальное состояние и шаги: S10 (humidity=20, temp=32, budget=3).
Ожидание с обоснованием: вентиляция забирает бюджет 3, насос OFF (R09). Факт: насос=ВКЛ, вентиляция=ВЫКЛ.
Серьёзность: Высокая. При перегреве теплицы вентиляция не включится.
Причина в candidate.js: В функции `order` насос стоял перед вентиляцией.
Исправление: `order: () => ['vent', 'pump']`.
Регрессия: S09 (PASS), S10 (стал PASS).

### BUG-03
Требование: R03
Заголовок: Самовольное снятие аварии при возрасте <= 30 без reset.
Начальное состояние и шаги: S15 (шаг 1: age=31, шаг 2: age=0, reset=false).
Ожидание с обоснованием: авария сохраняется (fault=true). Факт: авария снималась.
Серьёзность: Высокая. Игнорирование защитного отключения.
Причина в candidate.js: Ошибка в `hold`, условие `input.age > 30` приводило к отключению удержания при возрасте <= 30, даже без сброса.
Исправление: `hold: (previous, input) => previous.fault && !input.reset`.
Регрессия: S12 (шаг 1-2).

## 6. Изменение 2.1 и свойства
Изменение R05: порог включения полива смещен с 35 на 40. Затрагивает зону 35 <= humidity < 40. Файлы: change-impact.txt, delta-tests.json.
Минимальные различающие сценарии (D01-D04): D01 (humidity=37), D02 (humidity=39.9) падают на 2.0, потому что там OFF, а в 2.1 должно быть ON.
Свойства:
1. Расход ресурса: used = 2*pump + 3*vent <= budget.
2. Безопасность аварий: при fault=true все выключено.
3. Повторяемость: одинаковый сценарий дает одинаковый результат.
Бюджет 2->3 при двух запросах: при 2 включается насос (used=2), при 3 — вентиляция (used=3). Это следствие приоритета R09, а не ошибка.
