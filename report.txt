## 4. Дефекты

### BUG-01
Требование: R05. Насос включается при влажности ровно 35.
Воспроизведение: S02, шаг 1 (humidity=35, насос OFF). Ожидание: OFF. Факт на старой сборке: ON.
Код до: `pumpStart: humidity => humidity <= 35`
Код после: `pumpStart: humidity => humidity < 35`
Доказательство: protocol-before.txt, S02 FAIL. Регрессия: protocol-final.txt, S01, S02, S03 PASS.
Серьёзность: средняя (дребезг насоса у порога).

### BUG-02
Требование: R09. При бюджете 3 насос забирает ресурс раньше вентиляции.
Воспроизведение: S10, шаг 1 (humidity=20, temp=32, budget=3). Ожидание: vent ON, pump OFF. Факт на старой сборке: pump ON, vent OFF.
Код до: `order: () => ['pump', 'vent']`
Код после: `order: () => ['vent', 'pump']`
Доказательство: protocol-before.txt, S10 FAIL. Регрессия: protocol-final.txt, S09, S10 PASS.
Серьёзность: высокая (вентиляция не работает при перегреве).

### BUG-03
Требование: R03. Авария снимается без reset, если возраст данных не больше 30.
Воспроизведение: S15, шаг 2 (после age=31 — age=0, reset=false). Ожидание: fault=true. Факт на старой сборке: fault=false.
Код до: `hold: (previous, input) => previous.fault && !input.reset && input.age > 30`
Код после: `hold: (previous, input) => previous.fault && !input.reset`
Доказательство: protocol-before.txt, S15 FAIL. Регрессия: protocol-final.txt, S12, S15 PASS.
Серьёзность: высокая (защитная авария не держится).
